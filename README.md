# vesktop-imessage-theme
iMessage-style theme for Vesktop and Vencord

## Requirements

Enable Vencord's built-in **ThemeAttributes** plugin (Settings -> Vencord -> Plugins -> ThemeAttributes) so your own messages align to the right.

## Installation

### Option 1: Local Theme
1. Download `iMessage.theme.css` from this repository.
2. Open Vesktop Settings -> Themes -> **Open Themes Folder**.
3. Place `iMessage.theme.css` in that folder and enable it in the Local Themes tab.

### Option 2: QuickCSS
1. Open `iMessage.theme.css` and copy its contents.
2. Open Vesktop Settings -> Themes -> **Edit QuickCSS** and paste it in.

## Features
- iMessage-style blue sent bubbles on the right and adaptive received bubbles on the left across light, dark, and custom themes.
- Full pill bubbles with curved speech-bubble tails on the final message in each group.
- Compact top-left avatars aligned beside usernames for other users and bots (your own avatar and name are hidden).
- Timestamps rendered cleanly below messages, media, and message groups.
- Yellow full-bubble highlight on mentions, single aligned reply connectors, and visible slash-command headers.
- System messages (calls, boosts, joins, group notices) rendered natively and centered in chat.
